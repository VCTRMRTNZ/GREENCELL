# GREENCELL - Projecte final FES

AUTOR: VÍCTOR MARTÍNEZ - Fonament d'Enginyeria del Software - UAB 26/27

---

**ESTAT: En desenvolupament**

GreenCell és un analitzador del consum energètic d'equips de comunicació a estacions base.

L'MVP és un simulador de terminal que llegeix estacions i demanda per hora (CSV/JSON), reparteix la càrrega omplint primer les estacions més eficients, apaga les que queden sense càrrega i compara el consum amb l'escenari de referència (totes actives).
